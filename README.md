# Reclamation sequences

The videos of [Reclamation](https://github.com/Warzone2100/reclamation), an addon campaign for
[Warzone 2100](https://wz2100.net) by DARwins. This repository is the `sequences/` submodule of the
campaign's repository.

They need Warzone 2100 4.8.0 or later.
